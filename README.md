# Constituency War Room — Grievance Classification

## Problem
Predict department (8 classes) and urgency (3 levels) from citizen grievances sent to a constituency war room. Text is in English + code-mixed romanized Hindi/Kannada with typos and spelling variants.

## Approach
- **Model**: XLM-RoBERTa base with multi-task learning (joint department + urgency prediction)
- **Preprocessing**: Code-mixed text normalization, repeated character handling, keyword extraction
- **Training**: 5-fold stratified cross-validation with class weighting for imbalance
- **Inference**: Ensemble averaging across all fold models

## Key Design Decisions

1. **XLM-RoBERTa base**: Handles code-mixed text better than monolingual models via shared subword vocabulary that captures transliterated Hindi/Kannada patterns.

2. **Multi-task architecture**: Joint training on department + urgency with shared encoder. Urgency loss weighted at 0.4 because the brief explicitly states "the text carries most of the signal" and "nearly every message claims to be urgent — the word carries no signal, actual severity does."

3. **Class weights**: Inverse frequency weighting handles severe label imbalance (e.g., `welfare_schemes|routine` vs `healthcare|critical`).

4. **Code-mixed normalization**: 
   - Repeated character normalization ("sooooo" → "soo")
   - Filler word removal ("sir", "namaskara", "urgent")
   - Hindi script detection as feature
   - Keyword scoring for domain categories

5. **Stratified CV on department**: More stable than stratifying on 24 combined classes. Urgency is learned as a secondary task.

2. Add the competition dataset as input --> `train.csv` and `test.csv` 
3. Run all cells
4. `output_submission.csv` is genereated.
